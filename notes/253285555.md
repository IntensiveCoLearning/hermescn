# 残酷共学打卡 · 2026-08-27

## 今日主题：通过 Telegram 接入 Hermes

今天完成了 Hermes 与 Telegram 的首次接入，并用 Telegram 私聊完成了一次无副作用的往返测试。

### 环境核验

当前环境为 Hermes Agent `v0.20.0`，Python `3.11.15`，OpenAI SDK `2.24.0`。我依次核验了 Gateway 的帮助、profile 和运行状态，确认本机使用的是 `default` profile。

### Telegram 接入

通过 Hermes 的官方 onboarding 流程创建了 Telegram Bot，并将自己的 Telegram 账号加入 allowlist，同时设为 Home Channel。Bot Token 由 setup 保存到本机，没有写入聊天、截图、项目记录或打卡正文。

### 实际测试

我在 Telegram 中向 Hermes 发送了一个明确限定范围的测试请求：只回复指定文本，不执行文件写入、命令或外部操作。Hermes 成功返回指定文本；随后使用 `/status` 确认会话正常，已连接平台为 Telegram。

### 安全边界与发现

本次测试没有执行文件写入、命令执行、外部发布、删除、支付、交易或其他外部操作。allowlist 配置报告为只允许当前账号使用，但未额外使用第二个账号实测拒绝行为。

另外，setup 中选择了不自动启动，但本机 Hermes v0.20.0 生成的 macOS LaunchAgent 实际启用了登录自动启动和异常自动重启；这属于当前版本的服务配置实现限制，已记录为后续待处理事项。

### 今日收获

我确认了 Telegram 可以作为 Hermes 的消息入口，并理解了消息平台配置与 macOS Gateway 服务配置是两层不同的设置：前者可以在 Telegram 中进行部分运行时控制，后者需要在本机终端处理。
