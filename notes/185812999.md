# 2026-08-28

权限管理5问：

1. **它会接触什么？** 是一个练习文件，还是整个主目录、通讯录或服务器？
2. **它会改变什么？** 只读、新建、覆盖、删除，后果不同。
3. **能不能恢复？** 有备份、版本控制或撤销路径吗？
4. **结果会不会离开本机？** 联网、发消息、发布和提交交易会产生外部影响。
5. **是否涉及凭据、资金或生产系统？** 只要涉及其中一项，就提高一个风险等级。

# 2026-08-29

<br />

| **术语**        | **中文直觉**       | **本篇用途**                 |
| :------------ | :------------- | :----------------------- |
| 会话（session）   | 一项连续工作的对话记录    | 保存消息、工具调用、标题、模型和工作位置等信息  |
| 上下文（context）  | 模型当前这一轮实际拿到的信息 | 决定它此刻能依据什么判断，不等于全部历史永久可见 |
| 恢复（resume）    | 重新载入已保存会话继续工作  | 保留原任务的对话链和相关工具记录         |
| 压缩（compress）  | 把长上下文整理成较短延续   | 降低上下文占用，但不是删除历史或清除隐私     |
| 交接摘要（handoff） | 写在文件里的当前状态与下一步 | 在新旧会话之间提供可核对的最小上下文       |
