# 2026-08-27

Hermes 是一种 Harness 实现，区别于 Claude Code、Codex等专用于编程领域的实现，Hermes 和更早期的 OpenClaw 更像是钢铁侠中的贾维斯：

 

* 定位是长期个人助手，长期记忆是主要卖点
* 心智模型也不相同，Claude Code等实现记忆是基于项目的，而 Hermes 的记忆是跨项目的，同时可通过 Personality 根据场合以合适的方式行事

> 有趣的疑问：Hermes 新出的 Bot 模型心智模型又变了，Bot 间是独立记忆且技能不互通，什么场景适合使用Bot 而不是 Personality？

## 安装与体检

### 安装

#### Windows

```
iex (irm https://hermes-agent.nousresearch.com/install.ps1) 

hermes desktop

```

或者直接下载桌面版安装器

#### NixOS

```
# /etc/nixos/flake.nix (or your system flake)
{
  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixos-unstable";
    hermes-agent.url = "github:NousResearch/hermes-agent";
  };

  outputs = { nixpkgs, hermes-agent, ... }: {
    nixosConfigurations.your-host = nixpkgs.lib.nixosSystem {
      system = "x86_64-linux";
      modules = [
        hermes-agent.nixosModules.default
        ./configuration.nix
      ];
    };
  };
}

```

```
# configuration.nix
{ config, ... }: {
  services.hermes-agent = {
    enable = true;
    settings.model.default = "anthropic/claude-sonnet-4";
    environmentFiles = [ config.sops.secrets."hermes-env".path ];
    addToSystemPackages = true;
  };
}

```

## 第一个项目 GEM-reviewer

### 项目介绍

GEMs （Genome-scale metabolic models）是一种数学建模模型，用来模拟系统代谢或调控网络。此项目是个人实验项目，旨在探索 Hermes 能否从一次公开科学模型审查中形成可复用的 workflow，并在第二个模型上减少人工介入。尽量完全使用 Hermes Agent 规划并完成，我仅负责审阅。

项目地址： <https://github.com/henrycyberbio/gem-reviewer>

# 2026-08-29

### 工具、凭据和审批设置

#### 工具

Hermes 将 Agent 使用的工具分为 Tool 和 Toolset\[^1]：

* Tool 是一步操作
* Toolset 则是一组操作的集合

查看当前工具状态

```bash
hermes tools list
```

#### 凭据

\[^2]

```bash
hermes auth add <provider>              # 凭据添加

hermes auth list                        # 查看条目

hermes auth remove <provider> <target>  # 撤销条目

hermes auth logout <provider>           # 登出提供商
```

#### 审批

```
hermes config set approvals.mode smart
```
