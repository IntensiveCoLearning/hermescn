# Hermes 使用记录：首次真实任务

今天使用 **Hermes** 完成了教程中的第一个真实任务：

* 教程：[First Real Task](https://hermescn.org/docs/tutorials/guide/first-real-task)

## 1. 没有下载项目仓库，直接让 Agent 建立任务环境

这个任务需要的文件存储在项目仓库里，但由于任务说明已经列出了具体的文件内容，所以我没有下载项目仓库。

我直接把教程链接提供给 Hermes Agent，让它生成完成任务所需要的文件夹和文件。

## 2. Hermes 回答自身机制问题时，会主动检查源代码

完成教程任务之外，我还向 Hermes 询问了一些**关于它自身如何运作的问题**。

一个比较有意思的现象是：当问题涉及 Hermes 自身的行为时，它很多时候会**先查看源代码，再给出较为确定的答案**。

我继续追问它为什么这样做，得到的解释是，这种行为主要来自两个机制共同作用：

> **`hermes-agent`** skill 的硬性要求 + 系统级“不编造”规则。

## 3. Hermes 自带 OpenCode 的免费模型

昨天安装 Hermes 的时候，我设置了 ChatGPT 订阅作为 Provider。

今天偶然发现，**Hermes 自带了一批可以免费使用的模型**。

其中，我主要使用的是 **混元 3（Hy 3 free）**。

就今天的体验而言，无论是完成前面的教程任务，还是回答关于 Hermes 自身的问题，混元 3 的表现都挺不错。
