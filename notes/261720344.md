## 3. 我的收获（用自己话讲）

1. **已安装 ≠ 健康**。doctor 的价值在「验证」，不在「安装」。
2. **看懂警告比跑通命令更重要**。"⚠"多数是可选能力没配，不阻塞基础使用。
3. **OAuth 没登录 ≠ 配置失败**。API key 是同样有效的方式。
4. **WSL 是 Linux 环境**。路径以 `/home/...` 开头，和 Windows 不同，操作时要区分。
