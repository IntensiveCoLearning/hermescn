## 一、什么是 Hermes Agent？

**Hermes Agent** 是由开源 AI 研究组织 **Nous Research** 推出并采用 MIT 协议开源的自主式 AI 智能体（Autonomous AI Agent）框架 \[**[2.7](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fhermes-agent.org%2F)**, **[2.10](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fwww.tencentcloud.com%2Ftechpedia%2F143930%3Flang%3Den)**]。

它的官方核心标语是：**“The agent that grows with you”**（与你共同成长的智能体）\[**[2.8](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fgithub.com%2Fnousresearch%2Fhermes-agent)**, **[2.10](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fwww.tencentcloud.com%2Ftechpedia%2F143930%3Flang%3Den)**]。

### 定位差异

* **不同于 IDE 代码补全工具**：不局限于编辑器的代码辅助，而是一个全功能自主运行系统 \[**[2.7](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fhermes-agent.org%2F)**, **[2.12](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fhermes-agent.nousresearch.com%2Fdocs%2F)**]。
* **不同于传统的无状态 API 聊天套件（Chatbot Wrapper）**：普通对话机器人在会话结束后往往“遗忘一切”，而 Hermes Agent 具备**跨会话的持久记忆**与**闭环自我学习能力**，运行时间越长，越贴合使用者的工作习惯 \[**[2.3](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DGL67DEf2nyI)**, **[2.10](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fwww.tencentcloud.com%2Ftechpedia%2F143930%3Flang%3Den)**, **[2.15](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fopenhosst.com%2Fblog%2Fhermes-agent)**]。

## 二、三大核心支柱与设计哲学

codeCode

```
┌─────────────────────────────────────────────────────────────┐
│                      Hermes Agent 核心支柱                   │
├───────────────────┬─────────────────────┬───────────────────┤
│  1. 自托管与本地优先 │  2. 跨会话持久记忆  │  3. 闭环自进化学习 │
│  (Self-Hosted)    │ (Persistent Memory) │ (Self-Improving)  │
└───────────────────┴─────────────────────┴───────────────────┘
```

1. **自托管与隐私安全（Self-Hosted & Local First）**
   * **数据所有权**：对话历史、记忆画像与沉淀的技能全部保存在本地（如本地 SQLite 数据库等），不强制依赖中心化云端追踪与遥测 \[**[2.7](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fhermes-agent.org%2F)**, **[2.10](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fwww.tencentcloud.com%2Ftechpedia%2F143930%3Flang%3Den)**]。
   * **灵活的模型支持**：既可以接入本地离线大模型（如通过 Ollama/vLLM 运行的 Qwen、Llama 等），也可以灵活对接 OpenRouter、Claude、GPT 等云端模型服务 \[**[2.2](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3D12Cffcjha-w)**, **[2.3](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DGL67DEf2nyI)**, **[4.3](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DMTOsa6msrDs)**]。
2. **跨会话持久记忆（Persistent Memory & User Profile）**
   * 内置分层记忆与全文本检索（FTS5 / 向量化检索）机制 \[**[2.1](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DY3NDtqk6ags)**, **[2.10](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fwww.tencentcloud.com%2Ftechpedia%2F143930%3Flang%3Den)**]。
   * 能够记住用户的代码偏好、项目结构、个人风格以及数周乃至数月前的关键对话背景，无需在每次交互时重复输入长 Prompt \[**[2.3](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DGL67DEf2nyI)**, **[2.10](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fwww.tencentcloud.com%2Ftechpedia%2F143930%3Flang%3Den)**]。
3. **闭环自进化学习（Closed-Loop Learning System）**
   * 这是 Hermes Agent 最具辨识度的特性 \[**[2.10](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fwww.tencentcloud.com%2Ftechpedia%2F143930%3Flang%3Den)**]。
   * 学习循环流程：
     ```
     任务执行 (Execute)⟶结果反思 (Reflect)⟶技能固化 (Crystallize)⟶自动复用 (Reuse)任务执行 (Execute)⟶结果反思 (Reflect)⟶技能固化 (Crystallize)⟶自动复用 (Reuse)
     ```
     \[**[2.10](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fwww.tencentcloud.com%2Ftechpedia%2F143930%3Flang%3Den)**]

     <br />
   * 当 Agent 成功完成一项复杂的多步骤任务后，它会自动将这一工作流提炼为结构化的**技能（Skill）**，下次遇到同类问题时直接调用，大幅提升执行效率与稳定性 \[**[2.10](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fwww.tencentcloud.com%2Ftechpedia%2F143930%3Flang%3Den)**, **[4.21](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fwww.kimi.ai%2Fresources%2Fhermes-agent)**]。

## 三、关键能力与技术特性

### 1. Tools（工具）与 Skills（技能）分层体系

* **基础工具（Tools）**：提供底层原子能力，包括终端 Bash 执行、文件读写、网页搜索/抓取、浏览器自动化操控、视觉图像解析及 TTS 语音播报等 \[**[2.1](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DY3NDtqk6ags)**, **[2.5](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3D1ve4Atbqmoo)**, **[2.9](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fopenrouter.ai%2Fapps%2Fhermes-agent)**]。
* **高阶技能（Skills）**：由底层工具串联而成的复用型工作流模版（如“自动化竞品分析流程”、“代码自动化重构规范”），支持自动编写与用户自定义 \[**[2.1](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DY3NDtqk6ags)**, **[2.5](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3D1ve4Atbqmoo)**]。

### 2. 统一消息网关（Messaging Gateway）

Hermes 不仅运行在本地 CLI 终端或桌面端，还通过统一网关无缝接入外部聊天应用（如 **Telegram、Discord、Slack、WhatsApp**）\[**[2.2](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3D12Cffcjha-w)**, **[4.3](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DMTOsa6msrDs)**]。部署在 VPS 或轻量服务器后，用户可以随时随地通过手机 IM 软件向其派发长周期异步任务 \[**[2.4](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DmTYxpIRK7xA)**, **[2.12](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fhermes-agent.nousresearch.com%2Fdocs%2F)**]。

### 3. 定时自动化任务（Scheduled Tasks / Cron）

支持配置后台 Cron 定时任务，例如：

* 每天早晨定时收集特定领域最新论文与技术资讯并生成简报 \[**[2.3](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DGL67DEf2nyI)**, **[4.3](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DMTOsa6msrDs)**]；
* 周期性监控服务器状态与数据备份 \[**[2.4](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DmTYxpIRK7xA)**]。

### 4. MLOps 与自我迭代训练支持

Hermes Agent 具备生成轨迹导出功能（可导出为 ShareGPT 等微调格式），并支持与强化学习（RL）系统联动，将真实的交互轨迹转化为高质量训练数据，反哺后续模型训练 \[**[2.1](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DY3NDtqk6ags)**, **[2.7](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fhermes-agent.org%2F)**, **[2.13](https://www.google.com/url?sa=E\&q=https%3A%2F%2Fgregrobison.medium.com%2Farchitectural-and-strategic-analysis-of-the-hermes-agent-framework-and-the-psyche-decentralized-3f7d18fb40f6)**]。

# 2026-08-29 学习笔记 · Hermes 基础使用与第一次真实任务

## 今天学了什么

今天完成了 Hermes Agent 从「跑起来」到「用它完成真实任务」的关键一步，主要做了三件事：

1. 安装并运行了 Hermes Agent 和 Desktop，跑通第一次对话；
2. 用 Hermes 完成了一个带约束的文件任务（读三个源文件 → 生成 summary.md → 验收）；
3. 用 Hermes 完成残酷共学的打卡（理解打卡本质，并通过 Agent API 提交）。

## 实操记录

- 探索了 Hermes 的网络能力：`web_extract`（按 URL 读网页/PDF）、`web_search`（联网搜索），实测能直接拉取 Hermes 官方文档。
- 弄清了桌面端「工作目录」的查看与切换：Files 面板、Projects 侧边栏、Settings → Workspace。
- 完成 homework 文件任务：只读三个源文件 → 生成 summary.md（活动目标 / 学员反馈 / 下一步行动 / 信息缺口）→ 用「字节数 + 时间戳」对比验收，确认源文件未被改动。
- 打卡机制：读取网站的 llms.txt，确认打卡 = `POST /api/v1/me/check-ins`，配合 Idempotency-Key 幂等提交。

## 卡点 / 反思

- 一开始把「打卡」误判为网页手动点击或手动 git push，绕了弯路；读到 llms.txt 才确认是 Agent API。体会：做任务前先找「机器可读入口」（llms.txt / OpenAPI），比凭印象猜更快更准。
- 生成 summary.md 时学到：验收要拿客观证据（对比字节数、时间戳），而不是口头声称「没动原文件」。
- 提交打卡时遇到 Cloudflare 拦截（Python 请求被 1010 拒绝），改用 curl 通过——环境差异（TLS 指纹 / User-Agent）会影响请求是否被放行。
