# 2026-08-28

Hermes 使用情况与经验简要归档

日期：2026-08-28

一、今天使用的功能

1. 技能读取
   先读取相关技能说明，再开始处理，确保使用正确的方法。

2. 历史会话检索
   通过关键词查找之前的对话，并根据标题、时间和摘要定位相关内容。

3. 文件搜索与读取
   先搜索目标文件，再读取正文、表格和结构，避免盲目处理。

4. 文件复制与更新
   先复制原文件，再在副本上进行更新，避免影响原文件。

5. 程序化处理
   使用 Python 读取和处理文档中的文字、表格和段落。

6. 结果检查
   更新后重新读取文档内容和结构，确认内容已经写入。

7. 格式转换
   将更新后的文档转换为 PDF，确认文件可以正常打开和转换。

8. 并行调用
   将互不依赖的搜索、读取和检查操作同时执行，减少等待时间。

9. 任务清单
   使用任务清单记录处理进度，完成实际检查后再标记完成。

二、今天形成的经验

1. 重要文件应先复制，再处理副本，不要直接覆盖原文件。

2. 修改前应先确认文件结构，区分正文、表格和标题位置。

3. 写入成功不等于任务完成，必须重新读取结果进行确认。

4. 文件被其他程序占用时，替换操作可能失败，应先关闭占用程序。

5. 长内容或多步骤任务应先搜索定位，再读取相关部分。

6. 可以同时进行的操作应尽量并行执行，有先后依赖的操作仍需按顺序处理。

7. 工具没有实际执行的检查，不能在结果中写成已经完成。

8. 用户确认过的文字应保持原样，不擅自增删或改写。

9. 完成处理后，应同时检查内容、结构和文件是否可以正常打开。

三、简要结论

今天主要使用了 Hermes 的技能读取、历史检索、文件处理、程序化编辑、并行调用、任务清单和结果验证功能。

较可靠的通用流程是：

先读取和定位，再复制保留原件；在副本上处理后，重新检查正文和结构，执行可用的格式检查，最后只报告已经实际确认的结果。
