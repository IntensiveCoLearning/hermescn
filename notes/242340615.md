# 2026-08-29

探索hermes的研究方面的应用：



1. **用 Docker 在本地启动一个 SearXNG 实例**：



   Bash
   ```
   mkdir -p ~/searxng/searxng && cd ~/searxng

   ```
   创建一个 `docker-compose.yml` 文件：



   YAML
   ```
   services:
     searxng:
       image: searxng/searxng:latest
       container_name: searxng
       ports:
         - "8888:8080"
       volumes:
         - ./searxng:/etc/searxng:rw
       environment:
         - SEARXNG_BASE_URL=http://localhost:8888/
       restart: unless-stopped

   ```
   运行容器：



   Bash
   ```
   docker compose up -d

   ```
2. **开启 JSON API 支持**（Hermes 需要通过 JSON 与其通信）：



   Bash
   ```
   docker cp searxng:/etc/searxng/settings.yml ~/searxng/searxng/settings.yml

   ```
   打开 `~/searxng/searxng/settings.yml`，找到 `formats:` 这一行，把 `json` 加进去：



   YAML
   ```
   formats:
     - html
     - json

   ```
   放回并重启容器：



   Bash
   ```
   docker cp ~/searxng/searxng/settings.yml searxng:/etc/searxng/settings.yml
   docker restart searxng

   ```
3. **让 Hermes 关联该搜索源**：

   在终端运行 Hermes 的配置向导：



   Bash
   ```
   hermes tools

   ```
   或者直接修改 Hermes 的配置（如 `~/.hermes/config.yaml`），将搜索后端指定为 searxng 并指向本地端口：



   YAML
   ```
   web:
     search_backend: "searxng"

   ```
   同时设置环境变量：



   Bash
   ```
   export SEARXNG_URL=http://localhost:8888

   ```
