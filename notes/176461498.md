## 八、今日学习收获

通过 Day 1 的安装和诊断，我对 Hermes Agent 有了初步认识。

之前更容易把 Agent 理解成“一个可以聊天的 AI”，但实际安装和配置之后可以发现，一个可工作的 Agent 系统由多个部分组成：

```text
模型 Provider
      ↓
Agent Runtime
      ↓
Tools / Skills
      ↓
Memory / Session
      ↓
Terminal / Browser
      ↓
任务执行
      ↓
最终产物
```

因此，Agent 的核心并不只是模型本身，而是**模型、工具、运行环境和任务执行流程的组合**。

另外，`hermes doctor` 让我认识到 Agent 工具需要像开发环境一样进行系统性检查。出现某个功能未启用，并不一定代表安装失败，需要区分“核心运行环境问题”和“可选功能尚未配置”。

## 九、今日问题与解决

本次安装过程中主要遇到了三个问题：

### 1. Git SSH 无法连接

出现：

```text
Host key verification failed.
```

安装器自动切换 HTTPS，因此没有影响最终安装。

### 2. HTTPS Clone 中途断开

出现：

```text
RPC failed
early EOF
```

安装器自动切换 ZIP 下载，最终成功获取项目文件。

### 3. Nous Portal 首次授权超时

第一次设备授权没有在规定时间内完成，之后重新执行模型配置并完成 Portal OAuth 登录，最终解决。

这些问题让我认识到，在实际部署 Agent 时，网络、依赖、认证和工具链都可能成为影响运行的因素，需要根据日志定位，而不是简单反复安装。
