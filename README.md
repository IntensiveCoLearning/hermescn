# HermesCN 残酷共学第一期

## 共学简介

用一周时间学习 Hermes Agent，完成安装和基础使用，最终完成一个有输入、有产物、能验收、可复现的真实任务。

七天后，你将掌握一条真正能使用 Hermes 的完整路径：
`安装 → 第一次对话 → 明确任务 → 生成产物 → 将 Hermes 训练为生产级的 Agent`

最终成果是一个属于你自己的 Hermes 个人项目，可自由选择内容整理、社区运营、学习研究、软件开发或个人效率场景。

【基本规则】

* 周期：连续 7 天，每日投入约 45–90 分钟

* 形式：阅读短材料、动手实操、群内按模板打卡、和群友深度交流学习

* 注意：不要泄露任何 API Key、Token、私钥等凭据，不让 Agent 未经确认执行危险操作。

## 共学内容 / 课程信息

##### 每日主题安排

* Day 1：安装并完成第一次对话（环境验证与 doctor 诊断）

* Day 2：熟悉 Hermes 的基础使用

* Day 3：将模糊需求转成 Hermes 可理解的执行任务

* Day 4：管理会话与修正结果（理解 Hermes Profile）

* Day 5：安全边界与故障恢复（理解 Hermes 授权和审核机制）

* Day 6：完成个人场景项目

* Day 7：结营验收（项目展示和分享）

##### 结营产出

1. 可运行的 Hermes 环境与安装记录
2. 完整项目记录（代码/Skills/文章）
3. 加入 HermesCN 社区，完成注册（<https://hermescn.org/join>）

<br />

##### 课程资料

1. <https://hermescn.org/docs/tutorials>
2. <https://hermescn.org/best-practices>
